ABOUT MAXGUARD

Built as a local Windows security tool.

MaxGuard is a user-mode antivirus application with scanning, local detection, threat management, quarantine, history and configurable monitoring. It is designed to grow through future signature and application updates.

Security noteMaxGuard 1.0 is not a replacement for kernel-level security products such as Microsoft Defender. The website describes the features included in this project and does not claim capabilities that are not implemented.
